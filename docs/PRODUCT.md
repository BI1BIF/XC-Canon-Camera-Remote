# Canon Camera Remote Product Context

## Register

product

## Users

Camera operators use the three right-side buttons and the 240 by 320 display
to control Canon cameras. Local web configuration is primarily used on phones.

## Product Purpose

Provide XC control over local Wi-Fi and BR-E1-compatible Bluetooth remote
control. The two-mode home screen chooses the workflow; each workflow has its
own controls and relevant settings. The application manual is the root
[README](../README.md).

## Brand Personality

Direct, calm, responsive. Preserve the established application interface while
making actions and return destinations explicit.

## Anti-references

Avoid the baseline hardware-test menu, repeated mode selectors at different
levels, dead-end settings, and camera responses that make local edits flicker.

## Design Principles

- Keep mode selection on one home screen.
- Make returning to the remote and returning home distinct, visible actions.
- Show settings relevant to the active mode.
- Preserve context when returning from a child page.
- Keep button feedback immediate while camera commands run in the background.

## Accessibility and Inclusion

Retain legible text on the small display, verify Chinese glyph coverage, and
pair Tally and recording colors with text. The physical power button has no
exposed short-press event in the current board interface.
