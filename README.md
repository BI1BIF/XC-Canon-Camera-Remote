# AI Passport · Canon XC 与蓝牙相机遥控

用于 FoloToy AI Passport（ESP32-C3、8 MB Flash、240×320 RGB565）的独立固件。通过局域网的 Canon XC 接口读相机参数、按档调节曝光和色温，并用全屏外框显示相机返回的 Tally。也可通过低功耗蓝牙模拟 Canon BR-E1，用于支持佳能无线遥控器的相机。上游板级驱动保持原样。

## 机型范围

以下按 **2026 年 11 月 18 日**可查的佳能官方资料整理，是协议或原厂遥控器的兼容范围示例，**不代表本固件已逐机实测**。不能仅凭相机具有 Wi-Fi 或蓝牙判断可用。

| 连接方式 | 官方支持的代表机型 | 当前固件的范围 |
| --- | --- | --- |
| XC：Cinema EOS / 专业摄像机 | EOS C50、C70、C80、C400、C300 Mark III、C500 Mark II、XF605 | 曝光、色温、录像、Tally 及状态；已有 EOS C80 实机操作反馈，新版完整验收及其他机型仍待测试 |
| XC：PTZ 摄像机 | CR-N100、CR-N300、CR-N500、CR-N700、CR-X300 | 仅说明官方 XC 协议范围；本固件未实现云台操作，也未验证这些机型 |

XC 部分机型需要升级相机固件：佳能 RC-IP100 官方表列出 C70 至少 1.0.5.1、C300 Mark III 至少 1.0.1.1、C500 Mark II 至少 1.0.3.1、XF605 至少 1.0.1.1；具体连接方式及附件以相机说明书为准。参数能否修改、状态字段能否读取还取决于镜头、拍摄模式和相机回传。这里不将未确认支持 XC 的 EOS R5 C 列入 XC 名单。

蓝牙需相机支持 **BR-E1** 并完成无线遥控配对；视频模式还需相机允许遥控。EOS C50 的官方配件页将 BR-E1 明确标为“仅照片模式”，不能据此承诺蓝牙录像。蓝牙模式没有 XC 的曝光调节、Tally 或 REC 状态回读；“指令已发送”也不等于相机已经拍摄。

## 上手操作

开机先显示「佳能相机遥控器」功能首页：上下选「XC 遥控器」或「蓝牙遥控器」，单击确定进入。停留在首页不会自动跳转到记忆的相机。首次选择 XC 后才启动 Wi-Fi；直接选择蓝牙无需 Wi-Fi。功能首页是唯一选择遥控方式的位置。两个遥控页可双击确定进入当前模式的设置，首项「返回遥控界面」回到刚才的页面和选中位置；选「切换遥控方式」或长按确定回到功能首页。设置不再重复列出两个模式，蓝牙设置也不显示 XC 专属项目。

1. **连 Wi-Fi**：进入「XC 遥控器」后自动连接已存的 2.4 GHz 网络。首次使用，在设备上选「设置 Wi-Fi」，用手机系统相机扫屏幕二维码加入临时热点 `Passport-XC`（也可按屏幕密码手动加入），然后在浏览器访问 `http://192.168.4.1` 填本地 Wi-Fi。手机提示热点无互联网时，选择保持连接。提交后热点会自动关闭；长按确定可取消。
2. **连相机**：相机端开启 XC，确保设备和相机的 IPv4 网络互通。在设备上选「发现相机」，用上下选择、确定连接。也可选「手动连接相机」或「网页设置相机」，手机留在原 Wi-Fi，扫设备的网页二维码或浏览到设备 IP，填写**相机**的 IPv4、XC 端口（默认 80）及设备屏幕上的验证码。只有相机要求登录时才填写账号。首次连通后，设备会记住当前 Wi-Fi 和相机地址、端口、型号，以及相机提供的 MAC 地址。重启后选择 XC、连回同一 Wi-Fi 时自动尝试重连；若相机换了 IP，可重新发现，或在路由器上给相机保留固定 DHCP 地址。选择「断开并选相机」会清除记忆。需要 HTTP Digest 认证时，重启后按确定打开相机登录页，重新输入凭据。网页使用 HTTP，请在可信的本地网络操作。
3. **现场调节**：短按确定在光圈、快门、色温间循环。上键减一档，下键加一档；光圈按上时 F 值变小，开口变大。屏幕数字立即滚动到新值，同时在后台发送；连按快于相机回包时，同一参数只保留最新待发值。相机名和 IP 右侧显示录制分辨率与供电状态：外部供电显示电压，电池供电显示相机估算的剩余分钟数，未回传时显示 `--`。双击确定打开设置，可以勾选循环项、查看固件版本和 ISO/增益，或切换相机。长按确定开始或停止录像，主界面在相机型号上方以绿色 STBY、红色 REC 显示相机回传的状态（录制时 REC 前的红点每 1.8 秒呼吸一次，熄屏暂停），并显示存储卡剩余可录分钟数；相机未回传分钟数时显示 `--`。预设和 Wi-Fi 会保存；如需换网，在 XC 设置中选「更换 Wi-Fi」。
4. **读 Tally**：绿色/PVW 是待切入，红色/PGM 是播出，红色/PGM+ 是同时收到两种状态。亮屏时目标查询间隔约 100 毫秒；不支持单独查询时随完整状态读取。实际反馈时间取决于网络和相机。灰色表示未点亮、未知或离线，由屏幕文字区分。数据超过约 1.4 秒未刷新时，边框回到灰色。录像状态不会冒充 Tally。
5. **设备状态**：从 XC 连接页或当前模式的遥控设置进入。概览显示 Wi-Fi 名称、设备 IP、信号强度、信道、电量和电压；按下查看网关、子网掩码及最近一次成功的 XC 查询耗时，按上返回概览。XC 查询耗时包含相机处理时间。右上角每两秒更新电量，低于 20% 变为琥珀色，读不到时显示 `--%`。Passport 未向固件提供充电状态信号；充电时机身绿灯常亮，充满后熄灭。
6. **打开网页和改标题**：在线时，同一局域网的浏览器可访问「设备状态」里的 `http://设备IP`，直接修改标题并保存，无需在 Passport 上开启模式或输入验证码。修改相机地址或账号仍需在 Passport 上打开「网页设置相机」。首次配网或未联网时编辑标题，使用 `Passport-XC` 热点和 `http://192.168.4.1`。标题支持英文、数字和屏幕能显示的常用汉字；太长或含缺字的标题不会保存，留空恢复 `XC REMOTE`。保存后正常重启会保留。
7. **省电**：背光默认 65%，30 秒无功能键操作降至 15%，90 秒时熄灭。扫码设置期间保持 65%。黑屏时任意右侧功能键只唤屏；熄屏期间 Wi-Fi 和相机状态刷新仍在后台运行。

| 按键 | 遥控页 | 其他页面 |
| --- | --- | --- |
| 上 / 下 | 当前曝光或色温参数减 / 加一档 | 菜单选择上一项 / 下一项 |
| 确定短按 | 切换到下一个已启用的调节项；断线后尝试重连或进入登录 | 进入或执行选中项；相机状态页进入设备状态，设备状态页返回 |
| 确定长按 | XC 现场页开始 / 停止录像；蓝牙页返回功能首页 | XC 连接页和设置页返回功能首页；子页面返回上一级，预设自动保存；搜索 / 扫码设置取消并返回 |
| 确定双击 | 打开当前模式的遥控设置 | XC 连接页也可打开设置；功能首页和设置子页面忽略双击，避免误执行 |
| 任意功能键（黑屏） | 只唤屏 | 只唤屏 |
| 独立硬件电源键 | 按住约 0.5 秒开机、约 2 秒关机 | 同左；短按未接到固件 |

固件按 Canon XC Control Protocol Specifications（BPE-7216-005）的 `info.cgi`、`control.cgi` 实现，必要时短暂申请普通控制会话。先通过 mDNS 找佳能相机的 HTTP 服务并验证 XC，再用 Canon WebView 设备广播及本地 /24（或更小网段）的 HTTP 80 探测补充结果；设备隔离、不同网段、部分相机的认证方式或端口可能需要手动配置。相机上需要启用对应的手动调节模式（包括 Kelvin 白平衡）；软件不会替用户切换拍摄模式，也不写 Tally。未提供档位列表、模式不兼容或镜头不可控时，参数只读。

蓝牙使用方法：

1. 开机在功能首页选「蓝牙遥控器」，无需配 Wi-Fi。从 XC 切换时，双击确定进入设置，选「切换遥控方式」或长按确定回到功能首页，再选蓝牙。蓝牙页长按确定也可返回首页。切换模式保留 Wi-Fi 和相机记忆；先用过 XC 后切到蓝牙，已连接的 Wi-Fi 和网页改标题功能继续保留。
2. 在佳能相机菜单中选「连接至无线遥控器」并进入配对；在 Passport 选「配对相机」，相机出现确认时按机身确定。更换遥控器时，先按相机说明书清除旧遥控器的连接信息。Passport 记住最近一个完成配对的相机，进入蓝牙页时尝试重连。
3. 上下选择「拍照」「自动对焦」「启停录像」，单击确定执行。部分机型拍照要先设为遥控自拍驱动模式；录像要切到视频并启用「遥控」。断线后的第一次执行键只尝试重连，连接后再按一次才发送拍摄指令。双击确定打开蓝牙设置，长按确定返回功能首页。
4. 蓝牙页的「指令已发送」表示指令已提交。蓝牙遥控没有 XC 的 Tally、REC 回读或曝光参数；请在相机上确认是否执行。

蓝牙遥控的配对及拍照、对焦、录像操作流程参考 Taraskad3o 的 [M5Stack-AtomS3-BLE-Remote-for-Canon](https://github.com/Taraskad3o/M5Stack-AtomS3-BLE-Remote-for-Canon)，感谢原作者。当前版本针对 AI Passport 的三键和竖屏重新设计界面，蓝牙通信使用 ESP-IDF NimBLE 实现；BR-E1 协议参考 [ESP32 Canon BLE Remote](https://github.com/maxmacstn/ESP32-Canon-BLE-Remote) 和 [BR-E1 真机抓包记录](https://github.com/pulsar-trigger/pulsar-trigger/blob/e4bc6156e6dfdd0acedac0099e53b38f2db651d0/docs/canon-ble-research.md)。第三方版权与许可声明见 [THIRD_PARTY_NOTICES.txt](THIRD_PARTY_NOTICES.txt)。

设置中的「设备状态」、预设、相机状态、Wi-Fi 清除确认及扫码页面，返回时保留上一级的选中位置。设置页默认选中「返回遥控界面」，按一下即可回到遥控，不会误选另一种模式。清除 Wi-Fi 必须选「确认清除」后单击确定；双击不执行清除。配网成功返回打开它的页面，发现相机取消时也返回原页面。

构建：激活 ESP-IDF 5.5.3 后运行 `./tools/validate.sh`。产物为 `build/FoloToy-AI-Passport-full.bin`，合并镜像从 `0x0` 写入。合并刷写可能影响原有设置；真机验证前须确认目标设备和镜像。
